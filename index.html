ให้นักศึกษาพิมพ์คำตอบลงในช่องว่างใต้คำถามแต่ละข้อแล้วกดปุ่ม "ส่งคำตอบ" ระบบจะประเมินผลคำตอบพร้อมแสดงเฉลยทันที:
• [สีเขียว = ถูกต้องสมบูรณ์]: ตอบครบถ้วนตามหลักการทุกประเด็น
• [สีเหลือง = คำตอบเข้าโครงหรือเกือบถูก]: ตอบถูกหรือมีคีย์เวิร์ดที่เข้าโครงแม้เพียงเล็กน้อย
• [สีแดง = คำตอบไม่ถูกต้อง]: ไม่ตรงประเด็นหรือไม่ได้กรอกข้อมูล
1. จงเปรียบเทียบการทำงานของ JavaScript Output ระหว่าง element.innerHTML, element.innerText และ document.write() พร้อมระบุข้อควรระวังสำคัญของ document.write() ที่ชอบออกสอบ (4 คะแนน)
ให้อธิบายจุดประสงค์การทำงานของแต่ละคำสั่ง และผลกระทบหากเรียก document.write() ภายหลังจากที่หน้าเว็บโหลดเสร็จสมบูรณ์

2. จากตารางจับคู่ Syntax ของ Vanilla JavaScript เทียบกับ jQuery จงแปลงคำสั่งทั้ง 3 ข้อต่อไปนี้ให้อยู่ในรูป jQuery Library (3 คะแนน)
a) document.getElementById("demo").innerHTML = "<b>Hi</b>"; b) elem.style.color = "red"; c) elem.addEventListener("click", fn);

3. จงเปรียบเทียบการประกาศตัวแปร var, let และ const ในประเด็น Scope, Reassign, Redeclare และ Hoisting (4 คะแนน)
ระบุความแตกต่างของ Function Scope กับ Block Scope รวมถึงสถานะ TDZ (Temporal Dead Zone)

4. จงอธิบายความแตกต่างระหว่างตัวดำเนินการ == (Abstract Equality) กับ === (Strict Equality) พร้อมยกตัวอย่างผลลัพธ์ของ 5 == "5" และ 5 === "5" (3 คะแนน)

5. จงแปลงโครงสร้าง For Loop ต่อไปนี้ ให้ทำงานแบบเดียวกันโดยใช้ While Loop (3 คะแนน)
for (let i = 0; i < 5; i++) { console.log(i); }
ต้องระบุตำแหน่ง Initializer, Condition และ Incrementor ให้ถูกต้องสัมพันธ์กัน

6. ตามกระบวนการทำงานของฟังก์ชัน (Input -> Process -> Return Output) หากฟังก์ชันไม่มีคำสั่ง return หรือเรียกคำสั่ง return; เปล่าๆ จะเกิดผลลัพธ์อย่างไร และคำสั่ง return มีผลต่อการทำงานของโค้ดถัดไปในฟังก์ชันอย่างไร (3 คะแนน)

7. จงเปรียบเทียบ Array Methods ระหว่าง splice() กับ slice() ในประเด็นการเปลี่ยนแปลงข้อมูลใน Array เดิม (Mutate) และระบุข้อควรระวังเรื่องค่าดัชนีของ getMonth() ใน Date Object (3 คะแนน)

8. จงเขียนสูตรการสุ่มตัวเลขจำนวนเต็มช่วง min ถึง max (รวมทั้งสองค่า) ตาม Cheat Sheet และเปรียบเทียบความแตกต่างระหว่าง JSON.parse() กับ JSON.stringify() (3 คะแนน)
