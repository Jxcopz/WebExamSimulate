1. จงเปรียบเทียบความแตกต่างระหว่าง element.innerHTML, element.innerText และ document.write() พร้อมระบุข้อควรระวังสำคัญของ document.write() ตามแนวทาง W3Schools (4 คะแนน)
ให้อธิบายจุดประสงค์การทำงานของแต่ละคำสั่ง และผลกระทบหากเรียกใช้ document.write() หลังหน้าเว็บโหลดเสร็จสมบูรณ์

2. จากตารางจับคู่ Syntax ระหว่าง Vanilla JavaScript กับ jQuery จงแปลงคำสั่งต่อไปนี้ให้อยู่ในรูป jQuery Library (3 คะแนน)
a) document.getElementById("header").innerHTML = "<h1>Welcome</h1>"; b) document.querySelector(".box").style.display = "none"; c) document.getElementById("btnSubmit").addEventListener("click", doSubmit);

3. จงเปรียบเทียบการประกาศตัวแปรด้วย var, let และ const ในประเด็นเรื่อง Scope, Reassign, Redeclare และ Hoisting (4 คะแนน)
ให้อธิบายความแตกต่างของ Scope และพฤติกรรม Hoisting / Temporal Dead Zone (TDZ) ให้ชัดเจน

4. ตัวดำเนินการ == (Abstract Equality) และ === (Strict Equality) ใน JavaScript ทำงานต่างกันอย่างไร พร้อมยกตัวอย่างประกอบ (3 คะแนน)

5. จงแปลงโค้ดโครงสร้าง For Loop ต่อไปนี้ ให้ทำงานแบบเดียวกันโดยใช้ While Loop (3 คะแนน)
for (let i = 0; i < 5; i++) { console.log(i); }
